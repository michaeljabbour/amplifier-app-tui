The TUI keeps the conversation, pending actions, and status visible without requiring a browser.

## Basic flow

1. Type the task in plain language.
2. Let the assistant inspect the repo and propose work.
3. Read any pending change or command before approval.
4. Keep the verification command close to the task.

## Keyboard habits

- Use the visible key hints before memorizing shortcuts.
- Prefer one task per session when you need a clean review trail.
- Stop and rerun a focused test whenever the result should be deterministic.

## Command blocks

Command blocks in this site look copyable, but the site does not use JavaScript. Select the command text and copy it with your terminal or browser shortcut.
